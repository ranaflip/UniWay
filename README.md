🚗 UniWay: Optimized Multi-Stop Cab Management Solution
UniWay is a comprehensive mobile application designed to optimize and manage multi-stop pick-up and drop-off routes, primarily targeting educational institutions and corporate transportation. The platform ensures efficiency, minimizes travel time and distance, and provides a unified, native-like experience for both riders and drivers.

✨ Key Features
Unified Mobile Application: Single codebase developed with React Native to deliver a seamless, native experience for both iOS and Android platforms.

Dual Interface Design: Dedicated, optimized interfaces for both Riders (day scholars/passengers) and Drivers (fleet operators/cab captains).

Core Route Optimization Algorithm: Implements a custom-designed back-end algorithm to calculate the most optimized multi-stop pick-up and drop-off routes. This system efficiently serves multiple riders simultaneously while minimizing overall travel time and distance.

Scalable Cab Management: Provides a robust solution for managing a fleet of vehicles and their corresponding daily routes.

Validated Business Model: Successfully validated for business model, technical feasibility, and market fit through pre-incubation at AIC MUJ (Atal Incubation Centre, Manipal University Jaipur).
